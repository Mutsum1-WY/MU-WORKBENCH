# MU WORKBENCH · 安卓打包手册

> 目标：把 `D:\交互设计\MU-WORKBENCH\index.html`（网页版）装进一个原生外壳，
> 让**每日待办提醒由安卓系统闹钟执行——App 关掉、手机重启都还会响**。
> 数据依然只存在这台手机里，不联网、不上传。

---

### 附件下载（`MuNative.java`）

门户的附件挂在 `download.jsp` 后面，**必须带门户会话（JSESSIONID）才给文件**，而且会 302 到 CAS。
WebView 里直接跳会被弹回登录页，系统浏览器更没有这份会话，所以下载只能原生做：

```
JS  reader 点「下载」
  → window.MuNative.download(id, url, cookie, name, referer)
      Java 起线程，HttpURLConnection（带 Cookie / Referer / 手动跟随 302）
      边下边写：Android 10+ → MediaStore 下载目录 / 下载 / MU WORKBENCH
                 Android 9-  → app 自己的外部下载目录（FileProvider 打开）
  ← window.__muDl({id, act:'progress', pct})   ← 进度
  ← window.__muDl({id, ok:true, uri, name})    ← 完成，点这行就调 MuNative.open(uri, mime)
  ← window.__muDl({id, ok:false, msg})         ← 失败原因（会话过期 / 网络不通 / 门户错误码）
```

几个约束，改的时候别踩：

- **不用装新插件**：全程 `HttpURLConnection` + `MediaStore` + `FileProvider`，没加任何 gradle 依赖，
  APK 体积没涨（5.26 MB）。加插件要联网下包，这个项目是离线可编译的。
- **不要给 `MediaStore` 加 `IS_PENDING=0` 之外的花活**，`IS_PENDING=1` 写、写完置 0，中途失败要删掉这条记录，
  否则下载目录里会留半截文件。
- **`addJavascriptInterface` 只对本地页面开放**：app 的页面全部来自 `assets/public`，没有远程页面，
  所以不存在「远程页面拿到原生接口」的风险。以后要是加了远程页面，必须先把接口收回去。
- 网页版（没有 `window.MuNative`）点下载会提示一句然后交给系统浏览器，**不会点了没反应**。

## 二、出 APK（首次已经替你跑好环境）

双击 **`build-apk.bat`** 即可。它会依次做三件事：

1. `node sync-www.cjs` —— 把网页版最新代码复制进 `www/`
2. `npx cap sync android` —— 把网页和通知插件塞进原生工程
3. `gradlew.bat assembleDebug` —— 编译出 APK

成功后 APK 在：

```
D:\交互设计\MU-WORKBENCH-ANDROID\MU-WORKBENCH-debug.apk
```

第一次编译要下载 Gradle 和依赖（几分钟），之后增量编译约 30 秒 ~ 1 分钟。

### 已经替你装好的东西（都在 D 盘）

| 组件 | 位置 | 说明 |
|------|------|------|
| Temurin JDK 21 | `.toolchain\jdk` | OpenJDK 21.0.12，AGP 8.x 要求 JDK 17+ |
| Android cmdline-tools | `.toolchain\android-sdk\cmdline-tools\latest` | sdkmanager |
| platform-tools / android-35 / build-tools 35.0.0 | `.toolchain\android-sdk\` | 目标 SDK 35（安卓 15） |
| Gradle 8.11.1 + 全部依赖缓存 | `.gradle-home\` | 刻意放在 D 盘，不占 C 盘 |
| npm 缓存 | `.npm-cache\` | 同上 |

> ⚠️ **工程路径含中文的问题**：Android Gradle 插件默认拒绝在非 ASCII 路径（`D:\交互设计\...`）下构建。
> 已在 `android\gradle.properties` 里打开 `android.overridePathCheck=true`，实测可以正常编译出 APK。
> 万一以后升 AGP 后报 aapt2 之类的怪错，把整个 `MU-WORKBENCH-ANDROID` 文件夹挪到纯英文路径（例如 `D:\MU-WORKBENCH-ANDROID`）再编即可。

> ⚠️ **`local.properties` 不要手写**：Gradle 用 ISO-8859-1 读它，中文 SDK 路径会被写坏成 `????`。
> 现在构建脚本是直接设 `ANDROID_HOME` 环境变量（`build-apk.bat` 里已经设好），不依赖这个文件。

## 三、装到手机

- **数据线**：手机开「USB 调试」→ `adb install -r MU-WORKBENCH-debug.apk`
- **不用数据线**：把 APK 传到手机（微信/QQ/网盘）→ 点开安装 → 允许「安装未知应用」
- 装好后**第一次打开请点「允许通知」**；安卓 13+ 会主动弹权限框。
- 安卓 12+ 还想让它精确到分钟：设置页会多出一个「授予『精确闹钟』权限」按钮，点它跳到系统设置，允许「闹钟和提醒」。

## 四、待办的六种类型与「逐条提醒」

每条待办都有自己的**类型**和**提醒时间**（在「＋ 新建待办」的专注窗口里设置）：

| 类型 | 什么时候出现 | App 版怎么排闹钟 |
|------|-------------|-----------------|
| 单次 | 只在指定的那一天 | 一条一次性闹钟 |
| 每日 | 每天 | 一条「每天重复」的系统闹钟，永不过期 |
| 工作日 | 周一～周五，**自动跳过法定节假日、包含调休上班的周六日** | 逐日排具体日期（要按节假日算，系统闹钟表达不了「跳过某天」），往后排 21 天 |
| 休息日 | 周末与法定节假日 | 同上 |
| 自定义星期 | 自己勾周几 | 每个勾选的星期一条「每周重复」闹钟 |
| 每 N 天 | 从起始日算起每 N 天一次 | 向后排 8 次一次性闹钟 |

- **提醒时间**：默认填设置里的「默认提醒时间」（08:00），每条都能单独改，也可以点「不单独提醒」清空。
- **清空时间的待办**不会被单独提醒，而是进入「汇总兜底提醒」：到默认时间，把所有没设时间的待办合并成一条。
- **当天已完成**的待办，当天那条不会再响（重复类型下周照常）。
- 闹钟总量有上限（120 条），超了只保留最近的，避免吃满安卓的闹钟配额。

## 四b、提醒是怎么工作的
| 场景 | 网页版 | App 版 |
|------|--------|--------|
| 打开页面 | 弹今日待办横幅 + 提示音 | 一样 |
| 页面开着、某条待办到点 | 应用内弹窗 + 提示音 + 可选浏览器通知 | 一样 |
| **App 关掉 / 手机重启** | ❌ 不可能 | ✅ 系统闹钟照常响（每条待办独立提醒） |
| 通知内容 | 实时读取 | 排程那一刻的快照（每次改动数据、跨天、改时间都会自动重排刷新） |
| 点通知 | — | 直接回到「今日」页 |

单条通知长这样：标题 `⏰ 上班打卡`，正文 `工作日 · 高优先级 · 工作`；
汇总通知长这样：标题 `MU WORKBENCH · 汇总提醒`，正文 `读书 30 分钟、整理房间`。

## 四c、节假日数据（唯一联网的地方）

- 设置页 →「节假日与调休」→ **更新节假日数据**：拉一份公开的中国节假日/调休 JSON（jsDelivr，失败自动换 GitHub Raw），
  只发一个 GET，不带任何你的数据，拿到后永久缓存本机，之后完全离线可用。
- 不点它就永远不联网（默认就是没数据的），此时「工作日」按「周一～周五」判断。
- 「手动维护」里加的日期**优先级最高**，可以覆盖联网数据（比如公司自己放的假、临时调休）。
- 日历上：红字＋「休」＝法定节假日，橙「班」＝调休上班日。

## 四d、提示音与音量

**App 内提示音**（打开 App 时的横幅提醒、待办到点、番茄钟结束）是代码实时合成的，不加载任何音频文件：

- 设置页新增「**提示音音量**」三档：轻 / 标准 / **响亮（默认）**，点一下立刻试听；
- 老版本峰值只有 0.13，听起来很虚；现在峰值 0.95，并且音色从「单薄正弦」换成
  「三角波基音 + 高八度泛音 + 低八度垫底」，前面还串了一级限幅器（压缩器），所以既响又不破音。

**App 版的通知音**走安卓通知通道：

- 自带一个 0.9 秒的双音音效 `android\app\src\main\res\raw\mu_chime.wav`（峰值 -0.2dBFS、RMS -11.7dBFS，
  比系统默认通知音更响更亮），通道 `mu-todo2`，重要级设为最高（会响 + 弹横幅）；
- 安卓 8+ 的通道音效在**创建时固定**，所以换了新通道 id；旧通道 `mu-todo` 会在启动时自动删除，
  免得系统设置里出现两个同名通道；
- ⚠️ **最终音量由手机的通知音量决定**，App 改不了它。如果还是觉得小：
  系统设置 → 声音与振动 → **通知音量**调大；或在该应用的「通知类别」里给「待办提醒」单独换一个更响的音效。

## 四e、云邮教学空间（只在 App 版）

今日页会多出一张「云邮待办」卡片，设置页多一个「云邮教学空间」分组：填一次学工号 + 密码，
之后每次打开 App / 切回今日页自动拉一次云邮里的**未完成作业与测验**。

- 走的是云邮前端的**非官方接口**（`apiucloud.bupt.edu.cn`），细节见 `..\MU-WORKBENCH\_dev\云邮接口逆向笔记.md`；
  学校一升级就可能失效，届时按笔记里的「怎么重新排查」重来一遍。
- **凭据只存本机**，只会发给云邮服务器；但为了自动登录，密码是**明文**存的（设置里有「清除凭据」）。
- 只做了「看」：卡片点开就地展开（截止时间会换算成「还剩几天」），另有「在云邮中打开」跳去平台自己交作业，
  以及**本地**的「标记已处理」。
- **没有做 App 内自动提交作业**，原因写在笔记第 5 节（提交逻辑在懒加载 chunk 里、作业带附件要走文件上传、
  而且没有真实账号无法验证——盲提交可能把作业交成空内容）。
- 登录失败时，设置页会显示「① 登录 / ② 用户信息 / ③ 角色 / ④ 待办列表」哪一步断的 + 服务器原话，
  把那段文字发我就能定位。
- **新待办强提醒**：云邮里新出现作业/测验时，响一次 + 震动 + 弹窗（带截止时间）+ 立刻发系统通知；
  同一条只提醒一次，首次同步不打扰；设置页可单独开关。
- **踩过的坑**：第一版真机上报 `missing grant type`，原因是 CapacitorHttp 在请求头没有 `Content-Type` 时
  **会静默丢掉整个 body**；表单 POST 必须显式声明 `application/x-www-form-urlencoded`。已修，并补了会失败的回归测试。
- 网页版**没有**这个功能（按需求只在 App 版提供）。

## 五、数据与备份（重要）

- App 的数据存在 **WebView 自己的 localStorage** 里，跟手机浏览器**不互通**，也跟电脑不互通。
- 想搬家：在设置页「导出备份」拿到 JSON → 在新设备「导入备份」。
- **卸载 App 会连数据一起删掉**，卸载前先导出。
- 换手机、刷机同理，先用导出备份。

## 七、想正式发布（可选）

1. **换应用图标**：替换 `android\app\src\main\res\mipmap-*\ic_launcher.png`（以及 `ic_launcher_round.png`）。
2. **改包名**：`capacitor.config.json` 里的 `appId`（例如 `com.yourname.muworkbench`），改完 `npx cap sync android`。
3. **出正式包**：Android Studio 里 `Build > Generate Signed Bundle / APK`，或命令行用 `keytool` 生成签名 + `gradlew assembleRelease`。
   ⚠️ 签名要和调试包不同，**换签名必须卸载重装**（数据会没），所以先导出备份。
4. **权限说明**（上架应用商店时需要写进隐私政策）：数据全部只存在本机，不上传、没有账号。
   唯一可能发起网络请求的功能是设置页的「更新节假日数据」（默认不联网，只有用户主动点击才会拉一份公开节假日 JSON）。
   清单里的 `INTERNET` 权限是必需的：Capacitor 的 WebView 通过本机 `127.0.0.1` 的本地服务器加载页面，安卓要求建本地 socket 必须声明它。
   其余权限全部为本地提醒服务：`POST_NOTIFICATIONS`、`SCHEDULE_EXACT_ALARM`、`WAKE_LOCK`、`VIBRATE`、`RECEIVE_BOOT_COMPLETED`。

## 八、已知坑

| 现象 | 原因 / 解决 |
|------|------------|
| `build-apk.bat` 提示找不到 JDK | `.toolchain` 被删了，重跑 `_setup-toolchain.ps1` |
| Gradle 卡在下载 | 首次要下几百 MB；挂了代理就设 `GRADLE_USER_HOME` 后再试（已在 bat 里指向 D 盘） |
| 到点没响 / 延迟几分钟 | 安卓 12+ 没给「精确闹钟」权限，或系统省电策略限制了后台；去设置页点授权按钮，并把 App 加到「不受限制」 |
| 在「最近任务」里划掉 App 后不响 | 部分国产 ROM（小米/华为/OPPO/vivo）会连闹钟一起清掉，需在系统设置里允许「自启动 / 后台运行」 |
| 通知里写的还是旧待办 | 系统闹钟存的是排程时的快照，打开一次 App 就会自动刷新 |
| 想回到纯网页版 | 直接打开 `D:\交互设计\MU-WORKBENCH\index.html` 即可，App 和网页互不影响 |

## 九、这套外壳没有做的事

- ❌ 没有联网、没有服务器、没有账号、没有云端同步（刻意的）
- ❌ 没有 iOS 版（需要 Mac + Xcode + 开发者账号，成本完全不同）
- ❌ 没有后台常驻服务，靠的是系统闹钟，所以不需要一直占内存

## 十、装到手机后的 3 分钟自测清单

| 步骤 | 预期 |
|------|------|
| 1. 打开 App | 显示「今日」页，顶部弹出今日待办横幅 |
| 2. 首次会弹通知权限 | 点**允许**（没弹就去 系统设置 → 应用 → MU WORKBENCH → 通知，打开） |
| 3. 设置页确认「系统级每日提醒」显示**已注册：每天 08:00** | 说明系统闹钟已登记 |
| 4. 把提醒时间改成「当前时间 + 2 分钟」 | 状态立刻变成新的时间 |
| 5. 按 Home 键退出 App（**不要**在最近任务里划掉），锁屏等 2 分钟 | 通知栏弹出 `⏰ 待办标题` |
| 6. 点通知 | 直接回到 App 的「今日」页 |
| 7. 重启手机，再等一次 | 通知照常（靠 RECEIVE_BOOT_COMPLETED 自动重排） |
| 8. 关掉提醒总开关，再等 2 分钟 | 不再提醒（这条验证「关了真的会关」） |
| 9. 打开提醒，把某条待办的时间清空（点「不单独提醒」） | 到默认时间收到的是**一条汇总提醒**，里面列出这条待办 |
| 10. 新建一条「工作日」待办，设置页点「更新节假日数据」 | 日历上法定节假日变红＋「休」、调休上班日出现橙「班」；这条待办只在真正的工作日提醒 |

第 5 步如果没响：先看设置页是否提示「未授予精确闹钟权限」（点那个授权按钮），
再去系统设置把 App 的省电策略设为「不受限制 / 允许自启动」（小米、华为、OPPO、vivo 常见）。
