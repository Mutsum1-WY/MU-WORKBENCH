# MU WORKBENCH
作者本人只是fuking noob，本工具是纯粹的vibe coding产物，请勿上升至真人coding水平。

一个完全离线的个人工作台安卓 App：今日待办、课程表、可视化时钟、番茄钟、项目进度、日历、校内资讯、课程加分与作业档案。

## 这是什么

- **只做个人待办与提醒**。查成绩、选课、交作业请用学校的云邮 / 教务系统；这里只把「今天要做什么」摊平。
- **数据只在本机**。没有账号体系、没有后端、不上传；换设备用「导出备份 / 导入备份」搬家。
- **默认完全离线**。只有三处会联网，且都需要你手动操作：更新节假日、同步云邮待办、更新教务课表。
- **云邮 / 校内资讯是附加功能**：需要时到设置里填学校账号，凭据只存本机，可随时清除。

## 功能

| 模块 | 说明 |
|---|---|
| **今日** | 今日待办列表；逾期任务自动顺延并在原位划掉；顶部提醒横幅；云邮待办一并显示，并标出所属课程 |
| **待办类型** | 单次 / 每日 / 工作日（自动跳法定节假日）/ 休息日 / 自定义星期 / 每月几号（1–31 日多选，没这天的月份自动跳过）/ 每 N 天；可逐条设优先级、分类、提醒时间、子步骤 |
| **提醒** | 每条待办都会在到点时准时提醒；可设汇总兜底提醒、提示音三档、精确闹钟权限 |
| **课表** | 今日课程卡（现在上 / 下一节 / 剩余时间 / 本周课表）；默认用内置快照，填教务系统账号后可在设置里在线更新 |
| **时钟** | 表盘 + 数字时钟 + 今日进度；番茄钟（可关联待办）；秒表 / 倒计时 |
| **项目** | 可自建的进度卡片，每张卡下挂若干技能点，各自带进度条 |
| **日历** | 月历 + 年月快选 + 节假日 / 调休标记 + 长按加待办 + 给一段日期标「放假 / 调休上班」 |
| **资讯** | 校内通知 / 学术讲座，支持搜索、按时间与部门筛选、打开看正文与附件 |
| **课程** | 培养方案课程性价比（按学时 / 学分 / 考核方式排序）、课外加分记账与计分器、竞赛清单、综测自评 |
| **扫码签到** | 相机窗口扫课堂签到码，支持 1–4× 变焦，扫完可连续再扫；相机不可用时也能手动输入 |
| **作业档案** | 按学期归档已提交的作业，按课程分组，显示批改状态、分数与批改时间；点开可看批改情况、我的作业、优秀作业，附件可预览与下载 |
| **后台检查** | 约每 15 分钟检查云邮新作业与校内新通知，发现新内容发系统通知（默认关闭，可限制只在 Wi-Fi 下检查） |
| **设置** | 提醒、皮肤（P5R / P3R）与主题色、番茄钟时长、数据备份、云邮账号、教务课表账号、后台常驻 |

## 提醒有多快

| 场景 | 最快多久 |
|---|---|
| 待办**到点**提醒 | 准点（秒级） |
| 云邮**新作业 / 新测验** | 约 15 分钟（省电模式下可能更久） |
| 校内**新通知 / 讲座** | 约 15 分钟 |

15 分钟是安卓对后台任务的硬限制；要做到秒级只能靠服务器推送，那会把数据传出去，与「数据只在本机」冲突，所以没做。

后台检查默认关闭，在设置里打开；首次开启建议先点一次「立即检查一次」，确认通知能正常弹出（Android 13+ 需授予通知权限）。

## 界面

两套皮肤，在设置里随时切换（默认 P5R，切换立即生效并记住）：

- **P5R · 红黑斜切**：红 / 黑 / 米纸白三色，粗描边、硬投影、斜切与半调网点。
- **P3R · 蓝白斜切**：蓝白底 + 白色楔形高亮 + 冰青高光，跟随系统明暗分为白昼与月夜两版。
- **七套主题色**：血红、青碧、紫电、翠绿、樱粉、落日、月蓝；两套皮肤下都能换。
- **深色模式**：跟随系统，两套皮肤各有自己的深色外观。

*两套皮肤均为视觉致敬，与 ATLUS / SEGA 无关。*

## 使用

1. 从 [**Releases**](https://github.com/Mutsum1-WY/MU-WORKBENCH/releases/latest) 下载 APK 安装（Android 6.0+，首次安装需允许「安装未知来源应用」）。
2. 不装 App 也可以直接用浏览器打开 `MU-WORKBENCH/index.html`，除系统提醒与云邮相关功能外都能用。
3. 需要在线功能时，到设置里填写：云邮账号（同步待办、扫码签到、作业档案）、教务系统账号（在线更新课表）；不填就一直用内置数据。
4. 数据备份在设置里，可导出 / 导入。

## 已知限制

- 云邮、校内资讯、作业档案依赖学校系统，学校改版就可能失效；这几块在浏览器里不可用。
- 后台提醒最快约 15 分钟，省电模式或国产 ROM 限制后台时会更久；建议在系统设置里给 App 开「自启动」并允许后台运行。
- 后台检查依赖 App 里的登录状态，登录失效时会提示你打开 App 同步一次。
- 多设备不同步：没有服务端，换设备请用备份文件搬运。
- 未上架应用商店，装到新手机需要重新授权未知来源。
